# Multi-Step Login Application

A multi-step web application with login functionality and navigation through different options.

## Features
- User authentication with login page
- Dashboard with 5 navigation options
- Dynamic form inputs based on selected option
- Information display page
- Responsive design

## Pages
1. **index.html** - Login page
2. **dashboard.html** - Dashboard with 5 options
3. **form.html** - Dynamic form page
4. **info.html** - Information display page

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started
1. Open `index.html` in your browser
2. Enter any username and password to login
3. Select one of the 5 options from the dashboard
4. Fill in the required information and submit
5. View the information display page
